# 비주얼 스튜디오 코드

> VS Code 확장(베타)을 사용하면 IDE에 직접 통합된 기본 그래픽 인터페이스를 통해 Qwen의 변경 사항을 실시간으로 확인할 수 있으므로 Qwen Code에 더 쉽게 액세스하고 상호 작용할 수 있습니다.

### 특징

- **네이티브 IDE 경험**: Qwen 아이콘을 통해 액세스되는 전용 Qwen 코드 사이드바 패널
- **자동 수락 편집 모드**: Qwen의 변경 사항이 자동으로 적용됩니다.
- **파일 관리**: @-멘션 파일 또는 시스템 파일 선택기를 사용하여 파일 및 이미지 첨부
- **대화 기록**: 지난 대화에 접근
- **여러 세션**: 여러 Qwen Code 세션을 동시에 실행

### 요구사항

- VS 코드 1.85.0 이상

### 설치

다음에서 확장 프로그램을 다운로드하여 설치하세요.[Visual Studio Code 확장 마켓플레이스](https://marketplace.visualstudio.com/items?itemName=qwenlm.qwen-code-vscode-ide-companion).

## 문제 해결

### 확장 프로그램이 설치되지 않음

- VS Code 1.85.0 이상이 있는지 확인하세요.
- VS Code에 확장 프로그램을 설치할 수 있는 권한이 있는지 확인하세요.
- Marketplace 웹사이트에서 직접 설치해 보세요.

### Qwen 코드가 응답하지 않습니다

- 인터넷 연결을 확인하세요
- 문제가 지속되는지 확인하려면 새 대화를 시작하세요.
- [GitHub에 문제 제출](https://github.com/qwenlm/qwen-code/issues)문제가 계속되면

# 후속 제안

Qwen Code는 다음에 입력할 내용을 예측하고 입력 영역에 고스트 텍스트로 표시할 수 있습니다. 이 기능은 LLM 호출을 사용하여 대화 컨텍스트를 분석하고 자연스러운 다음 단계 제안을 생성합니다.

이 기능은 CLI에서 엔드 투 엔드로 작동합니다. WebUI에서는 후크 및 UI 배관을 사용할 수 있지만 호스트 애플리케이션은 제안 생성을 트리거하고 제안이 표시되도록 후속 상태를 연결해야 합니다.

## 작동 방식

Qwen Code가 응답을 마친 후 짧은 지연(\~300ms) 후에 입력 영역에 제안이 흐린 텍스트로 표시됩니다. 예를 들어, 버그를 수정한 후 다음이 표시될 수 있습니다.

```
> run the tests
```

제안은 대화 기록을 모델에 전송하여 생성되며, 모델은 사용자가 자연스럽게 다음에 입력할 내용을 예측합니다. 응답에 명시적인 팁이 포함된 경우(예:`Tip: type post comments to publish findings`), 제안된 작업이 자동으로 추출됩니다.

## 제안 수락

| 열쇠          | 행동                                   |
| ------------- | -------------------------------------- |
| `Tab`         | 제안을 수락하고 입력에 입력하세요.     |
| `Enter`       | 제안을 수락하고 즉시 제출하세요.       |
| `Right Arrow` | 제안을 수락하고 입력에 입력하세요.     |
| 모든 입력     | 제안을 무시하고 정상적으로 입력하세요. |

## 제안이 나타날 때

다음 조건이 모두 충족되면 제안이 생성됩니다.

- 모델이 응답을 완료했습니다(스트리밍 중이 아님).
- 대화에서 최소 2번의 모델 전환이 발생했습니다.
- 최근 응답에는 오류가 없습니다.
- 보류 중인 확인 대화 상자가 없습니다(예: 셸 확인, 권한).
- 승인 모드가 다음으로 설정되지 않았습니다.`plan`
- 이 기능은 설정에서 활성화되어 있습니다(기본적으로 활성화되어 있음)

비대화형 모드(예: 헤드리스/SDK 모드)에서는 제안이 표시되지 않습니다.

다음과 같은 경우 제안이 자동으로 무시됩니다.

- 당신은 입력을 시작합니다
- 새로운 모델 차례가 시작됩니다
- 제안이 수락되었습니다.

## 빠른 모델

기본적으로 제안은 기본 대화와 동일한 모델을 사용합니다. 더 빠르고 저렴한 제안을 위해 빠른 전용 모델을 구성하세요.

### 명령을 통해

```
/model --fast qwen3-coder-flash
```

또는 사용`/model --fast`(모델 이름 없이) 선택 대화 상자를 엽니다.

### settings.json을 통해

```json
{
  "fastModel": "qwen3-coder-flash"
}
```

빠른 모델은 신속한 제안과 추측 실행에 사용됩니다. 구성되지 않은 경우 기본 대화 모델이 대체 모델로 사용됩니다.

사고/추론 모드는 기본 모델의 사고 구성에 관계없이 모든 배경 작업(제안 생성 및 추측)에 대해 자동으로 비활성화됩니다. 이렇게 하면 이러한 작업에 필요하지 않은 내부 추론에 토큰이 낭비되는 것을 방지할 수 있습니다.

## 구성

이러한 설정은 다음에서 구성할 수 있습니다.`settings.json`:

| 환경                           | 유형 | 기본    | 설명                                             |
| ------------------------------ | ---- | ------- | ------------------------------------------------ |
| `ui.enableFollowupSuggestions` | 부울 | `true`  | 후속 제안 활성화 또는 비활성화                   |
| `ui.enableCacheSharing`        | 부울 | `true`  | 캐시 인식 분기 쿼리를 사용하여 비용 절감(실험적) |
| `ui.enableSpeculation`         | 부울 | `false` | 제출 전 추측적으로 제안 실행(실험적)             |
| `fastModel`                    | 끈   | `""`    | 신속한 제안과 투기적 실행을 위한 모델            |

### 예

```json
{
  "fastModel": "qwen3-coder-flash",
  "ui": {
    "enableFollowupSuggestions": true,
    "enableCacheSharing": true
  }
}
```

## 모니터링

제안 모델 사용법은 다음에 나타납니다.`/stats`제안 생성을 위해 빠른 모델에서 사용되는 토큰을 보여주는 출력입니다.

빠른 모델은 다음에도 표시됩니다.`/about`"빠른 모델"에서 출력됩니다.

## 제안 품질

제안사항은 품질 필터를 거쳐 유용한지 확인합니다.

- 2\~12단어(CJK: 2\~30자), 총 100자 미만이어야 합니다.
- 평가할 수 없습니다("좋아 보입니다", "고마워요").
- AI 음성("Let me...", "I'll...")을 사용할 수 없습니다.
- 여러 문장이거나 서식(markdown, 줄 바꿈)을 포함할 수 없습니다.
- 메타 논평('제안할 내용 없음', '침묵')을 사용할 수 없습니다.
- 오류 메시지나 접두사 라벨은 사용할 수 없습니다('제안: ...').
- 단일 단어 제안은 일반적인 명령(예, 커밋, 푸시 등)에만 허용됩니다.
- 슬래시 명령(예:`/commit`)은 항상 한 단어로 된 제안으로 허용됩니다.

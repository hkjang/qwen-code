# Qwen 코드 문서

Qwen Code 문서에 오신 것을 환영합니다. Qwen Code는 터미널에 존재하는 에이전트 코딩 도구로, 그 어느 때보다 빠르게 아이디어를 코드로 전환할 수 있도록 도와줍니다.

- 기본 설치 및 설정
- 일반적인 사용 패턴
- 특징 및 성능
- 구성 옵션
- 문제 해결

Qwen Code에 기여하고 개발하는 방법을 알아보세요. 이 섹션에서는 다음 내용을 다룹니다.
